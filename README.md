# SQM Insight · AI 供应商质量管理演示系统

一个可以在本机运行的小型“AI 供应商质量管理系统”，把 **质量数据治理 → 智能预警 → RAG 知识检索 → 8D 改善闭环** 串成一条完整的业务链路，用于面试演示和内部方案验证。

- 后端：Python 标准库 + SQLite，**不需要安装任何第三方包**
- 前端：原生 JavaScript 单页应用，图表为手绘 SVG，**完全离线可用**
- 数据：10 家模拟供应商、12 个物料、约 26 周 / 624 个 IQC 批次、21 份质量知识文件，全部为模拟数据

> 演示数据不对应任何真实企业。系统给出的是数据证据、风险排序和历史经验参考；停线、放行、特采与责任判定仍须按企业授权流程由责任人决定。

## 快速开始

**Windows**：安装 Python 3.9+（安装时勾选 *Add Python to PATH*），双击 `start_windows.bat`，浏览器会自动打开 <http://127.0.0.1:8765/>。

**macOS / Linux**：

```bash
python3 run.py            # 首次启动自动生成演示数据
python3 run.py --reset    # 清空并重新生成演示数据
python3 run.py --port 9000 --no-browser
```

**不想装 Python**：运行一次 `python tools/build_static.py` 生成 `dist/sqm_insight_offline.html`，这个单文件可以直接双击在浏览器打开（静态快照，导入和大模型功能不可用）。

## 功能模块

| 模块 | 能做什么 |
| --- | --- |
| 质量总览 | 近 30 天批次、拒收率、抽样 PPM、待处理预警、未关闭 8D；PPM 周趋势、缺陷 Pareto、供应商排名 |
| 供应商画像 | 综合评分与等级、每个物料的 p 控制图（含 4M 变更标记）、批次追溯、4M 变更记录、8D 履历、相关知识文件 |
| 智能预警 | 三层预警：规则预警、统计预警、AI 关联分析（4M 变更关联 + 历史案例 + 可解释风险评分），自动生成异常分析简报，一键发起 8D |
| AI 质量知识库 | 中文检索 8D、PFMEA、SOP、审核报告、经验教训；缺陷同义词自动扩展；按“历史原因 / 措施 / 效果验证”给出带出处编号的证据式摘要 |
| 质量数据治理 | CSV 导入校验（缺失、重复、编码、日期、单位、不良数口径、缺陷名称映射）、质量评分与四个维度、系统数据健康检查、指标口径、标准缺陷代码库、导出 CSV |
| 改善闭环 · 8D | D1–D8 阶段推进；关闭时强制填写根因、永久对策、效果验证，关闭后自动生成 8D 报告写入知识库，下次同类问题可被检索到 |

## 五分钟演示路线

1. **质量总览**：PPM 最近 4 周明显超出目标，右侧列出需优先处理的预警。
2. **智能预警 → 恒润滤材 异味异常上升**：控制图上评估窗口内多批超出控制上限；黑色“料”标记是 10 月初的热熔胶变更，且未按 PCN 通知；风险评分逐项可追溯。
3. 同页 **历史相似案例**：检索到 2025 年同供应商的异味 8D（根因正是热熔胶换型和熟化时间不足）；**异常分析简报** 可直接复制发给供应商。
4. 点击 **发起 8D**，进入 **改善闭环** 填写根因和对策；尝试不填效果验证直接关闭，系统会拦截。
5. 补充效果验证后关闭，到 **AI 质量知识库** 搜索刚填的根因关键词，新 8D 已经回写进知识库。
6. **质量数据治理**：示例 CSV 中的 16 行包含大小写混用、供应商名称代替编码、`200pcs`、`1.5%`、不良数大于抽样数、重复批次、“外观不良”等笼统描述，系统逐行标注修正或拦截。

## 方法说明

**统计判异。** 每个物料以 42 天之前的批次为历史基线估计不良率 p̄，最近 42 天为评估窗口。IQC 抽样量小、不良率低（n·p 常小于 1），正态近似的 3σ 控制限误差大，所以用 **二项分布精确尾概率** 计算每批的控制上限，阈值取与 3σ / 2σ / 1σ 相同的单侧概率（0.00135 / 0.02275 / 0.1587）。判异规则只看恶化方向：

- R1：单批超出控制上限（≈3σ）
- R2：连续 3 批中 2 批超出 2σ
- R3：连续 5 批中 4 批超出 1σ
- 趋势：近 28 天合并样本不良率 ≥ 基线 2 倍，且二项检验 p < 0.001

等级：R1 ≥ 2 批为高；R1 一批、R2、R3 或 3 倍以上趋势为中；其余为低。

**风险评分（第三层）。** 可解释的加权求和，满分 100：统计异常强度（≤30）、缺陷严重度（A 25 / B 15 / C 5）、关键物料 10、异常前 30 天有 4M 变更 15（未按 PCN 通知再加 5）、同供应商同类问题历史复发 10（其他供应商有同类案例 5）、战略/核心供应商 5。评分用于排序和分派，不是黑箱预测模型。

**知识检索。** 中文按字二元组、英文按单词切分，BM25 打分；去掉“原因 / 对策 / 怎么”等每份 8D 都有的意图词；查询中的缺陷同义词（刮伤、Scratch → 划伤）自动扩展为标准名称。摘要直接摘自命中文件的“根本原因 / 对策 / 效果验证”章节并标注出处，不经过大模型改写。

**供应商评分。** PPM 得分 50 × max(0, 1 − PPM/20000) ＋ 批次合格率 × 30 ＋ 8D 响应 20 − 8×逾期数 − 3×未关闭数；A ≥ 90，B ≥ 80，C ≥ 70，D < 70。所有指标口径在“质量数据治理”页面集中列出。

## 接入自己的资料

- **知识文件**：把 `.md` / `.txt` 放进 `knowledge_base/`，然后 `python run.py --reset`。文件头部可选写元数据（编号、标题、类型、供应商、物料、缺陷代码、日期），正文用 `## 标题` 分章节；章节名含“根本原因”“永久对策”“效果验证”等关键词时会被摘要引用。参考现有文件格式。
- **IQC 数据**：在“质量数据治理”页面粘贴或选择 CSV，列名见 `samples/iqc_import_sample.csv`，校验通过的行才会入库。
- **主数据**：供应商、物料、缺陷代码与同义词、抽样方案、评分规则都在 `sqm/reference.py`。

## 可选：启用大模型

默认完全离线，数据不出本机。如果企业已批准使用外部模型服务，可以开启“大模型生成回答”和“简报润色”：

```bash
pip install anthropic
set ANTHROPIC_API_KEY=你的密钥      # macOS / Linux 用 export
set SQM_LLM=on                       # 明确授权把检索到的资料发送给模型服务
python run.py
```

模型只基于检索到的资料回答，并要求标注出处；不会给出停线、放行或责任判定结论。默认模型可用 `SQM_LLM_MODEL` 修改。涉及供应商成本、客诉、图纸、客户专有资料时，请先确认企业数据安全要求。

## 项目结构

```
run.py                 启动入口
start_windows.bat      Windows 双击启动
sqm/
  reference.py         主数据与业务口径（缺陷代码、供应商、抽样方案、评分规则）
  db.py                SQLite 表结构
  seed.py              演示数据生成（固定随机种子）
  stats.py             二项分布尾概率与控制限
  analytics.py         指标、供应商评分、控制图判异、三层预警、简报
  knowledge.py         知识库检索与证据式摘要
  governance.py        导入校验、标准化、健康检查、导出
  capa.py              8D 流程与知识库回写
  llm.py               可选的大模型调用（默认关闭）
  server.py            HTTP API 与静态文件服务
web/                   前端（index.html、app.js、app.css；static-backend.js 用于离线单文件版）
knowledge_base/        21 份示例知识文件
samples/               导入样例 CSV
tools/build_static.py  生成单文件离线演示版
tests/                 python -m unittest discover -s tests
```
